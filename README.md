## 📖 Overview

PayURupee is a full-stack digital wallet platform designed to simplify personal finance management. It provides users with a secure and intuitive environment for handling digital transactions, monitoring spending habits, scheduling payments, and managing wallet operations.

The platform combines modern design, responsive user experience, and robust backend architecture to deliver a seamless financial ecosystem.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/SOUVIKSB1/PayURupee.git
```

### Navigate to Project Directory

```bash
cd PayURupee
```

### Install Dependencies

```bash
npm install
```

### Start Backend

```bash
cd Backend
npm install
npm start
```

### Start Frontend

```bash
cd Frontend
npm install
npm run dev
```
